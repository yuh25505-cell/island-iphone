# 弹窗与控件

## 专属弹窗（全 App 统一一套，不用安卓默认弹窗）

### 确认弹窗（Alert）

- 宽 270，圆角 14，居中，背景用卡片色
- 标题 Headline 17 居中，正文 Footnote 13 居中
- 按钮区：两个按钮左右排列，超过两个上下排列，按钮高 44，按钮之间细分割线
- 主要按钮 Semibold 主题色；危险按钮红色
- 弹出动效：从 1.1 倍缩到 1.0 + 淡入，约 0.25 秒；背景黑色高 30%

### 底部操作表（Action Sheet）

- 从底部升起，圆角 14，左右留 8 边距
- 选项行高 57，居中文字，危险项红色
- 底部单独一个「取消」卡片，Semibold

### 底部卡片页（Sheet）

- 顶部圆角 12，顶部小把手，可拖到中等高度或全高
- 下滑关闭，背景页缩小一点点露出层次

### 菜单（长按/点击更多）

- 圆角 14，宽约 250，行高 44，图标在右侧，危险项红色

### 提示条（Toast）

- 居中偏上，圆角 14，深灰底白字，停留 2 秒

弹窗规则：都要适配日间/夜间；都支持返回键/手势关闭（危险确认例外可禁止点击空白关闭）；不加小字注释。

## 控件

| 控件 | 规格 |
|---|---|
| 开关 | 宽 51×高 31，开启绿色 #34C759，关闭灰填充，圆珠 27 白色带轻微阴影，动画 0.25 秒 |
| 主要按钮 | 高 50，圆角 14，主题色底白字 Semibold 17 |
| 次要按钮 | 淺主题色底或灰底，主题色字 |
| 文字按钮 | 只有主题色文字，点击透明度 0.4 |
| 输入框 | 高 44，圆角 10，填充色底，占位文字次要色 |
| 搜索框 | 高 36，圆角 10，左侧放大镜 |
| 分段控件 | 高 32，圆角 9，选中白块滑动 |
| 滑块 | 轨道高 4，圆点 28 |
| 选择器（滚轮） | 行高 34，中间高亮带 |
| 加载菊花 | 20 小圆 / 37 大圆 |
| 头像 | 圆形 |
| 选中勾 | 主题色细勾，放在行右侧 |

图标：使用线性、粗细统一的图标，风格接近 SF Symbols（苹果的线性符号库），统一线宽。
