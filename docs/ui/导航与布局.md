# 导航与布局

## 尺寸（pt = dp）

| 元素 | 尺寸 |
|---|---|
| 状态栏 | 跟随系统 |
| 导航栏（小标题） | 高 44 |
| 导航栏（大标题展开） | 高约 96 |
| 标签栏 | 高 49，图标 25–28，文字 10 |
| 列表行 | 最小高 44 |
| 页面左右边距 | 16（大屏可 20） |
| 分组卡片圆角 | 10–12（连续圆角） |
| 按钮最小点击区域 | 44×44 |
| 搜索框 | 高 36，圆角 10 |
| 大圆角按钮（主要） | 高 50，圆角 14 |
| 头像（列表） | 40–60 |
| 桌面图标 | 60，圆角约 13.5 |

## 导航

1. 层级导航：点进下一级，左上角返回按钮（蓝色箭头 + 上一级标题），支持左滑/右滑返回
2. 平级导航：底部标签栏，最多 5 个，选中用主题色，未选中用灰色
3. 大标题：页面顶部大标题，向上滚动时渐变成居中小标题
4. 导航栏右侧最多 2–3 个操作，用文字或线性图标
5. 模态页（从底部弹出的卡片页）：可下滑关闭，顶部圆角 10–14，顶部有小把手
6. 搜索框放在大标题下方，下拉露出

## 列表与分组

- 设置类页面用「分组底 + 白色圆角卡片」
- 卡片内行与行之间细分割线，左侧缩进与文字对齐
- 行右侧常见：箭头（灰色细 chevron）、开关、当前值
- 左滑行出现操作按钮（删除红色、更多灰色）
- 列表有空状态页：居中图标 + 一句标题 + 一个主要按钮（按本项目规则不加小字说明）

## 安全区

- 顶部避开状态栏、刷海和打孔；底部避开手势条
- 所有页面支持高度变化和横屏（可锁定竖屏）

## 聊天页特殊布局

- 气泡圆角 18，最大宽度约屏宽 75%，左右边距 16
- 自己发的气泡在右侧（主题色），对方在左侧（灰色）
- 输入栏固定在底部，跟随键盘
- 消息列表倒序排列，分页加载
