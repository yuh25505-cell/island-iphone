## 规则

1. 全部颜色定义成主题变量，代码里不写死颜色值
2. 日间/夜间/跟随系统都从同一套变量切换，关闭跟随系统时也能手动切
3. 夜间用纯黑底 + 层级灰表达层次，不用阴影表达高度
4. 主题色默认系统蓝，可由用户更换
5. 危险操作用红色，成功用绿色
6. 文字和背景对比度至少 4.5:1
7. 不用液态玻璃，不大面积模糊。导航栏、标签栏可用带轻微透明的纯色底
