# UI 规范目录

依据：苹果官方 Human Interface Guidelines（developer.apple.com/design/human-interface-guidelines）的 iOS 部分整理。默认采用传统 iOS（非液态玻璃）的视觉：纯色底、细分割线、圆角卡片。

单位：苹果的 pt 对应安卓的 dp（文字用 sp），1:1 换算。

| 文件 | 内容 |
|---|---|
| 苹果官方文档索引.md | 苹果官方全部 UI 文档的索引、怎么读、按任务查的速查表（做界面先查这个） |
| 排版.md | 字体、字号、行高、字重、文字排版 |
| 颜色.md | 系统颜色、背景层级、文字颜色、日夜间对照 |
| 导航与布局.md | 导航栏、标签栏、列表、边距、圆角、安全区 |
| 弹窗与控件.md | 专属弹窗样式、开关、按钮、输入框等 |
| 动效与手势.md | 动画、转场、手势、触感反馈 |

核心原则（苹果官方）：清晰（Clarity）、顺从内容（Deference）、层次（Depth）。

做界面的顺序：先查《苹果官方文档索引.md》的速查表 → 看本目录里已整理的数字 → 不够再去读官方原文 → 把新的数字补回整理文档。
