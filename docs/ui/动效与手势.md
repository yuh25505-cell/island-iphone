# 动效与手势

## 动画原则（苹果官方）

1. 动画要有目的，帮助理解状态变化，不炫技
2. 跟手：拖动时元素要跟手指走，松手后带惯性收尾
3. 可中断：动画中用户再次操作，立刻响应，不等动画播完
4. 弹簧为主：用弹簧曲线代替匀速和生硬缓入缓出
5. 尊重系统「减弱动态效果」设置

## 时长与曲线

| 场景 | 时长 | 曲线 |
|---|---|---|
| 页面推入/返回 | 约 0.35 秒 | 弹簧（阻尼约 0.85），新页从右滑入，旧页左移约 30% 并变暗 |
| 底部 Sheet | 约 0.4 秒 | 弹簧 |
| 弹窗 Alert | 约 0.25 秒 | 缩放 1.1→1.0 + 淡入 |
| 开关 | 0.25 秒 | 弹簧 |
| 点击按钮反馈 | 0.1 秒 | 透明度/高亮即时 |
| 列表高亮 | 按下即显，松开 0.2 秒淡出 | 线性 |
| 升减高度（键盘、展开） | 0.25 秒 | 缓出 |
| 图标拖动/抖动（桌面编辑） | 循环 | 轻微旋转 ±1° |

## 手势

| 手势 | 用途 |
|---|---|
| 左滑/右滑（屏幕边缘） | 返回上一步（对接安卓原生预测性返回） |
| 下拉 | 刷新、露出搜索 |
| 下滑关闭 | 卡片页、大图预览 |
| 左滑行 | 行操作（删除等） |
| 长按 | 菜单、消息操作、桌面进入编辑 |
| 双指缩放 | 图片、相册 |
| 上划（锁屏） | 解锁 |

## 触感反馈

- 点击开关、选择、长按菜弹出、删除确认时给轻微震动（调用安卓系统震动 API）
- 用户可在设置里关闭震动

## 性能要求

- 动画保持 60fps 以上；不在主线程做重活
- 不在动画中触发重组大面积界面
- 长列表滚动中不加载大图
