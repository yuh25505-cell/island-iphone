# 苹果官方 UI 文档索引

用途：做界面时先查这张表，找到对应的苹果官方页面，再去读原文。本仓库只放索引和整理，不复制苹果原文。

## 怎么读

- 官方总入口：https://developer.apple.com/design/human-interface-guidelines
- 每个页面网址：`https://developer.apple.com/design/human-interface-guidelines/<页面名>`
- 网址最后加 `.md` 能拿到纯文字版，适合 AI 读取，例如 `.../typography.md`
- AI 读取时：用联网搜索找到该页链接后再打开（直接拼网址可能被拒）
- 官方设计资源下载（图标尺寸、模板）：https://developer.apple.com/design/resources/
- 官方更新记录：https://developer.apple.com/design/whats-new/

## 重要提醒

苹果最新版文档大量讲「Liquid Glass（液态玻璃）」。岛屿机不用液态玻璃，读文档时跳过这部分，只取尺寸、布局、交互、文字、颜色规则，视觉按传统 iOS（纯色底、细分割线）。只看 iOS/iPadOS 部分，其他平台内容不读。

## 三、组件（Components）

页面名按苹果官方目录分类整理，未逐个打开核对；若某页打不开，用联网搜索找同名页面，并把正确的页面名改回本表。苹果新版把导航栏并进了 toolbars。

### 内容 Content

charts（图表）、image-views（图片视图）、text-views（文字视图）、web-views（不用，项目禁止网页）

### 布局与组织 Layout and organization

boxes、collections（网格，相册用）、column-views、disclosure-controls（展开收起）、labels、lists-and-tables（列表，最常用）、lockups、outline-views、split-views、tab-views

### 菜单与操作 Menus and actions

activity-views（分享面板）、buttons（按钮）、context-menus（长按菜单）、edit-menus（编辑菜单）、menus、pop-up-buttons、pull-down-buttons、toolbars（工具栏/导航栏）

### 导航与搜索 Navigation and search

path-controls、search-fields（搜索框）、sidebars、tab-bars（标签栏）、token-fields

### 呈现 Presentation

action-sheets（底部操作表）、alerts（确认弹窗）、page-controls（分页小点）、panels、popovers、scroll-views、sheets（底部卡片页）、windows

### 选择与输入 Selection and input

color-wells（颜色选择）、combo-boxes、digit-entry-views、image-wells、pickers（滚轮/日期选择）、segmented-controls（分段控件）、sliders（滑块）、steppers、text-fields（输入框）、toggles（开关）、virtual-keyboards（键盘）

### 状态 Status

activity-rings、gauges、progress-indicators（进度条/加载圈）、rating-indicators

### 系统体验 System experiences

app-shortcuts、controls、live-activities、notifications（通知）、status-bars（状态栏）、widgets（桌面组件）、home-screen-quick-actions（桌面长按图标菜单）

## 五、读取后的整理

读完某页，把关键数字（尺寸、行高、颜色、时长）补进对应的整理文档（排版.md、颜色.md、导航与布局.md、弹窗与控件.md、动效与手势.md），下次就不用再读原文。
