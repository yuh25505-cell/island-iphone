# 苹果官方 UI 文档索引

用途：做界面时先查这张表，找到对应的苹果官方页面，再去读原文。本仓库只放索引和整理，不复制苹果原文。

## 怎么读

- 官方总入口：https://developer.apple.com/design/human-interface-guidelines
- 每个页面网址：`https://developer.apple.com/design/human-interface-guidelines/<页面名>`
- 网址最后加 `.md` 能拿到纯文字版，适合 AI 读取，例如 `.../typography.md`
- AI 读取时：用联网搜索找到该页链接后再打开（直接拼网址可能被拒）
- 官方设计资源下载（图标尺寸、模板）：https://developer.apple.com/design/resources/
- 官方更新记录：https://developer.apple.com/design/whats-new/

## 重要提醒

1. 苹果最新版文档大量讲「Liquid Glass（液态玻璃）」。岛屿机不用液态玻璃，读文档时跳过这部分，只取尺寸、布局、交互、文字、颜色规则，视觉按传统 iOS（纯色底、细分割线）。只看 iOS/iPadOS 部分。
2. 苹果的 SF Pro 字体和 SF Symbols 图标库，授权只允许在苹果平台使用，不能放进安卓 APK。字体用安卓系统默认字体或用户上传的 ttf，只学苹果的字号、行高、字重数值；图标方案待定（做主屏幕时和用户确认），在确认前不引入任何图标库。
3. 苹果文档是写给苹果系统的。下表「安卓能用吗」一列说明每页在安卓原生里怎么用：
   - **直接做**：只是尺寸、颜色、布局、交互规则，照着自己画即可
   - **参考**：苹果系统自带的功能，安卓上没有或不同，只学样子，在 App 内自己做一套
   - **不用**：电脑、手表、眼镜专用，或项目规则禁止

## 三、组件（Components）

页面名按苹果官方目录分类整理，只核对了「导航与搜索」这一小类，其他未逐个打开。若某页打不开，用联网搜索找同名页面，并把正确的页面名改回本表。苹果新版把导航栏并进了 toolbars。

### 直接做（只是尺寸、颜色、布局、交互规则）

| 分类 | 页面名 |
|---|---|
| 内容 | charts、image-views、text-views |
| 布局与组织 | boxes、collections（相册网格）、disclosure-controls（展开收起）、labels、lists-and-tables（最常用）、lockups |
| 菜单与操作 | buttons、context-menus（长按菜单）、edit-menus、menus、pop-up-buttons、pull-down-buttons、toolbars（导航栏） |
| 导航与搜索 | search-fields、tab-bars |
| 呈现 | action-sheets、alerts、page-controls、popovers、scroll-views、sheets |
| 选择与输入 | pickers、segmented-controls、sliders、steppers、text-fields、toggles |
| 状态 | progress-indicators、gauges、rating-indicators |

### 参考（苹果系统自带功能，安卓上没有或不同，只学样子）

| 页面名 | 在岛屿机里怎么用 |
|---|---|
| activity-views | 分享面板，调用安卓系统分享，只学触发位置 |
| widgets | 桌面组件，在 App 内的桌面里自己做 |
| home-screen-quick-actions | 长按图标菜单，在 App 内桌面自己做 |
| notifications | 通知样式，锁屏和通知条在 App 内自己做；真正的系统通知用安卓的 |
| status-bars | 状态栏由安卓系统控制，只学显隐与颜色搭配 |
| virtual-keyboards | 键盘是安卓系统的，只学输入栏跟随键盘的方式 |
| live-activities、app-shortcuts、controls | 苹果独有，只学灵感 |

### 不用

- 电脑/手表/眼镜专用：path-controls、sidebars、token-fields、column-views、outline-views、split-views、combo-boxes、panels、windows、color-wells、image-wells、activity-rings、digit-entry-views、tab-views
- 项目禁止：web-views（不套网页）
