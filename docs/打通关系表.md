# 打通关系表

规则:
- 每一对都是**双向**:A 能给 B 什么、B 能给 A 什么,都要写。
- 每一对互通都有**开关**,user 可关闭。
- 互通遵守角色隔离:只在同一个 `charId` 范围内流动,除非特别说明。
- 互通的数据走共用读取流程或统一事件通道,不许两个 App 私下直接读对方数据库。

## 一、底座类(对所有 App 生效)

| 底座 | 给所有 App | 所有 App 给它 |
|---|---|---|
| 预设 | 提示词模块、共用读取流程、驱动状态摘要 | 各 App 的事件(聊天、日程、发帖等)推动驱动状态与念头池 |
| 世界书 | 设定注入(按挂载选择) | 稳定的新设定可"建议存为条目",user 确认后写入 |
| 设置 | API 槽位、通知开关、备份、更新 | 各 App 的数据纳入备份;各 App 的通知请求走统一通知 |
| 外观 | 主题、字体、壁纸、图标 | 各 App 的类名/组件接受装修样式 |

## 二、两两互通

| # | App A ↔ App B | A → B | B → A |
|---|---|---|---|
| 1 | chat ↔ 屿年 | 聊天里的重要事件生成屿年候选记录(user 确认或自动) | 屿年里 char 当年的阶段与现状(学业/工作/职位)注入聊天,影响说话内容 |
| 2 | chat ↔ 相册 | char 在聊天里发的照片、截图自动入对应相册 | 相册里的照片可被发进聊天,char 可引用"上次拍的那张" |
| 3 | chat ↔ 日历 | 聊天里约定的事(周六见面)自动生成日程 | 日程决定 char 此刻在做什么、回复快慢、是否方便聊天 |
| 4 | chat ↔ 音乐 | 聊天里分享的歌入音乐收藏/播放;"一起听"同步当前歌曲 | 正在播放的歌、听歌记录进入聊天上下文,char 会评论 |
| 5 | chat ↔ 相遇 | 聊天近况作为相遇开场背景 | 相遇结束的摘要(开了记忆开关时)进入聊天记忆,聊天里可聊起"那天见面" |
| 6 | chat ↔ 查岗 | 聊天消息可被关联角色看到(按查岗规则) | 查岗中看到的内容,让 char 在聊天里有反应(吃醋、关心等) |
| 7 | chat ↔ 论坛 | 聊天里的话题成为 char 发帖的素材 | char 的帖子、评论可在聊天里被提起或转发给 user |
| 8 | chat ↔ 文学城 | 聊天里的情节可选作同人文素材 | char 读/写的文章成为聊天话题,文章可分享进聊天 |
| 9 | chat ↔ 情侣空间 | 聊天里的亲密事件可入情侣空间(纪念、日记素材) | 便利贴、"我爱你"打卡、日记内容可被聊天引用,char 会提起 |
| 10 | chat ↔ 美团 | 聊天里可点外卖送给对方,订单以卡片形式发出 | 订单状态(已送达等)回到聊天,char 会反应 |
| 11 | chat ↔ 栖迟 | 白天聊天的近况成为梦境素材 | 计入记忆的梦境进入聊天,char 会提到"我昨晚梦到" |
| 12 | 日历 ↔ 情侣空间 | 日历显示纪念日、周年 | 情侣空间纪念日同步到日历,周年发系统通知 |
| 13 | 日历 ↔ 美团 | 日程里的饭点/加班触发 char 点外卖 | 外卖订单记入当天日程 |
| 14 | 日历 ↔ 相遇 | 日程空闲时段可约相遇 | 相遇约定写入日历 |
| 15 | 屿年 ↔ 相遇 | 屿年里的过去可作为相遇"穿越"素材 | 相遇补全的过去回写屿年,标记为补记 |
| 16 | 屿年 ↔ 栖迟 | 屿年的经历成为梦的素材 | 梦里反复出现的主题可生成屿年候选(心结、愿望) |
| 17 | 相册 ↔ 情侣空间 | 相册照片可放进情侣相册合集 | 情侣空间里的合照、回忆图存回相册 |
| 18 | 相册 ↔ 相遇 | 相册照片作为相遇场景的物件 | 相遇里 char 拍的照存入相册 |
| 19 | 相册 ↔ 美团 | 相册里的食物照可成为点单灵感 | 订单晒图存入相册 |
| 20 | 论坛 ↔ 文学城 | 论坛帖子可引到文学城作品 | 文学城新作品自动在论坛有讨论帖 |
| 21 | 论坛 ↔ 查岗 | 论坛小号发言可被查岗看到 | 查岗中发现的线索成为论坛发帖/评论的素材 |
| 22 | 音乐 ↔ 情侣空间 | 当前歌曲可设为"我们的歌" | 情侣歌单同步到音乐 |
| 23 | 情侣空间 ↔ 栖迟 | 情侣空间的日记、心愿作为梦的素材 | 梦里出现的情节可生成情侣空间便利贴/日记 |
| 24 | 相遇 ↔ 栖迟 | 相遇中的情节成为梦的素材 | 梦里的场景可"接续"为相遇开场(不混入 if 线番外) |
| 25 | 世界书 ↔ 屿年 | 世界书的人生设定决定屿年的初始轨迹 | 屿年里新阶段可建议更新世界书条目 |
| 26 | 查岗 ↔ 相册 | 被查岗的角色相册(非私密)可被看到 | 查岗中发现的图片可存入相册 |

> 栖迟的 if 线番外:不进记忆,**不连通**聊天和相遇,不出现在任何互通里。

## 三、互通改动规则

- 新增或修改互通,先在本表改,再动代码。
- 改共用部分时,逐条检查本表受影响的行。
