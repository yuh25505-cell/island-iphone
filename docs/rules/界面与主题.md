# 界面与主题规则

## 一、总风格

- 全局完全复刻 Apple 原生手机的视觉、交互、配色、动效。
- **不要液态玻璃效果**(不做那种折射、通透的新玻璃质感)。
- 苹果官方设计依据会在下一轮搜索整理,存进 `docs/design/`,之后所有界面以它为准。
- 不使用安卓默认控件外观,统一用自绘的苹果风组件(放 `core/`)。

## 二、日夜间(每个新页面/弹窗/功能都必须适配)

四种状态:
1. 日间
2. 夜间
3. 跟随系统(默认)
4. 软件关闭"跟随系统"后,手动固定日间或夜间

要求:
- 所有颜色只从主题里取,禁止在页面里写死颜色值。
- 切换时立即生效,不用重启。
- 新页面做完,日间/夜间/跟随系统/手动 四种都要自己过一遍。

## 三、返回手势

- 所有页面、弹窗支持原生的左滑、右滑返回上一步。
- 弹窗也要能下拉关闭或侧滑返回(视弹窗类型,以苹果习惯为准)。
- 手势与列表横向滑动冲突时,列表优先,返回手势从屏幕边缘起算。

## 四、弹窗

- 所有弹窗使用**专属弹窗样式**,统一放在 `core/dialog/`,各 App 不许自己画弹窗。
- 弹窗种类:确认框、输入框、选择菜单、底部面板、全屏面板。
- 弹窗同样适配日夜间和返回手势。

## 五、不加小字注释和说明

开发页面、功能、弹窗时,不在界面上加小字注释、提示说明文字。界面靠图标、命名、布局自己说明。

## 六、类名(给 user 美化用)

- 桌面组件:每个组件有类名,user 可按类名自定义制作和导入。
- chat 私聊:气泡、头像、时间、输入栏、顶栏、背景等各部分都有类名,支持 QQ 主题式美化。
- 类名一旦发布不随便改;要改必须保留旧名兼容。
- 类名清单维护在 `docs/design/类名表.md`(下一轮建立)。

## 七、字体

- 支持导入多个 ttf 字体并切换。
- emoji 字体也可多个切换。
- 两者可同时全局使用;删除正在使用的字体时先退回系统字体。

## 八、流畅度

- 长列表用懒加载列表,只画屏幕里看得见的。
- 动画不卡界面线程;滚动期间不做重计算。
- 图片按显示大小加载,不加载原图。
