# App 互通表

要求：双向互通。「记忆」列指是否写入对应 char 的记忆。

| 互通 | 谁给谁什么 | 收到后做什么 | 进记忆 |
|---|---|---|---|
| 聊天 ⇄ 日历 | 日历→聊天：char 当前日程（上课、开会、睡觉）；聊天→日历：聊天里约定的见面、提醒 | 聊天按日程调整在线状态、回复速度、语气；约定自动生成日程 | 约定进记忆 |
| 聊天 ⇄ 相册 | 聊天→相册：截图、收到的照片；相册→聊天：char 或 user 发出的照片 | 互存互发，保留来源 | 发照片事件进记忆 |
| 聊天 ⇄ 相遇 | 聊天→相遇：聊天里的约定和近况；相遇→聊天：线下发生的事 | 相遇开场读取近况；结束后聊天里能提起 | 是（相遇可选计入） |
| 相遇 ⇄ 屿年 | 相遇→屿年：重要经历；屿年→相遇：过去与成长 | 经历沉淀为成长记录；相遇引用成长背景；「穿越/过去」玩法产生的事写成真正的记忆 | 是 |
| 聊天 ⇄ 屿年 | 聊天→屿年：重要转折；屿年→聊天：当前人生阶段 | 人生阶段影响聊天内容 | 是 |
| 聊天 ⇄ 朋友圈 | 聊天→朋友圈：聊到的事可成动态；朋友圈→聊天：互相点赞评论 | 评论、点赞可在聊天里被提起 | 重要互动进记忆 |
| 朋友圈 ⇄ 论坛 | 朋友圈→论坛：同一角色的表达风格一致；论坛→朋友圈：看到的话题 | 内容互相引用，NPC 可共用 | 否（可选） |
| 聊天 ⇄ 论坛 | 论坛→聊天：char 在论坛的发帖、看到的内容；聊天→论坛：聊过的话题 | char 可在聊天里聊起自己发的帖 | 重要的进记忆 |
| 查岗 ⇄ 聊天 | 聊天→查岗：对方收到的其他人消息；查岗→聊天：查看后的反应 | 查岗行为会产生双方在聊天里的反应 | 是 |
| 情侣空间 ⇄ 聊天 | 聊天→空间：聊天里的甜蜜瞬间可存便利贴；空间→聊天：char 写的日记、便利贴提醒 | 互相引用 | 是 |
| 情侣空间 ⇄ 日历 | 纪念日双向同步 | 到日子系统通知 | 纪念日进记忆 |
| 日历 ⇄ 屿年 | 屿年→日历：人生阶段决定日程类型；日历→屿年：长期日程沉淀成成长 | 日常更真实 | 否 |
| 日历 ⇄ 内在驱动 | 日程影响疲劳压力；驱动高时生成想做的事 | 见内在驱动系统 | 否 |
| 相册 ⇄ 相遇 | 相遇里的照片存相册；相册里的照片可在相遇提起 | 互通 | 是 |
| 栖迟 ⇄ 记忆 | 栖迟可按记忆生成梦境；栖迟内容由 user 选择是否计入记忆 | 可选 | 可选 |
| 美团 ⇄ 聊天 | 美团→聊天：点外卖、送礼；聊天→美团：char 提出想吃的 | 订单事件在聊天里出现 | 是 |
| 音乐 ⇄ 聊天 | 一起听歌、分享歌曲；聊天里提到的歌可加入歌单 | 听歌状态显示在聊天 | 可选 |
| 设置/预设/世界书/音乐 | 全局共用 | 所有 App 都读 | — |

## 明确不互通

栖迟里的「番外小剧场」：不计入记忆，不连通聊天和相遇。

## 补充建议

- 文学城 ⇄ 论坛：发布的小说可在论坛里被 NPC 评论，char 读到后产生念头
- 美团 ⇄ 日历：外卖送达时间写入日程
- 相册 ⇄ 朋友圈：相册里的照片可发朋友圈
