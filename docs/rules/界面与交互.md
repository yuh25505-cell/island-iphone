# 界面与交互

1. UI 完全复刻 iPhone 原生：配色、动效、交互、页面样式一样丝滑，不要液态玻璃。依据 `docs/ui/`
2. 所有弹窗必须是苹果 iOS 弹窗样式（确认弹窗 Alert、底部操作表 Action Sheet、底部卡片页 Sheet、菜单），全 App 统一一套，绝不使用安卓默认弹窗和安卓 Material 弹窗。第一次用到时做成公共组件，之后全部复用
3. 每个新页面/弹窗/功能都适配：日间、夜间、跟随系统；用户可手动固定日间或夜间；软件内关闭「跟随系统」后，日间/夜间切换也要正常
4. 支持安卓原生左滑/右滑返回上一步（含预测性返回动画）
5. 界面里不加小字注释和说明文字，靠清晰的图标和标题表达
6. 用户可创建的内容一起做好编辑和删除；可开启的功能一起做好关闭方式
7. 长列表用懒加载；动画全部走 60fps 以上；点击反馈要即时
8. 空状态、加载中、出错状态都要有，且样式统一
9. 触控区域至少 44×44 dp
10. 键盘弹出时输入框不被遮挡，输入不延迟
11. 不单独做预览页和控件展示页，控件在真实页面里顺路建、顺路验收
