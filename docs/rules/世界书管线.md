# 世界书管线

## 注入位置（四个）

| 位置 | 放在哪里 |
|---|---|
| 最高 | 整条提示词最前面，用于最高优先级设定（破限） |
| 前 | 角色资料之前 |
| 中 | 角色资料与记忆之后 |
| 后 | 上下文深度/聊天记录、本轮输入之前 |

顺序从上到下：最高 → 前 → 角色资料 → … → 记忆 → 中 → … → 后 → 聊天记录 → 本轮输入。完整排序见《预设与提示词.md》。

## 规则

- 注入顺序：先按位置，再按用户排好的顺序，同位置内按分类顺序
- 可分类：分类可新建、改名、排序、删除；条目可移动分类
- 每条可单独开关；可绑定到指定 char、群聊或全局
- 所有能生成内容的地方都能挂世界书：聊天、相遇、日历、论坛、文学城、栖迟、屿年、朋友圈等，每个 App 在自己设置里选择挂哪些
- 世界书只通过「共用读取流程」注入，各 App 不得自己另写一套
- 活人感提示词也放在世界书里，按位置注入
- “最高”“前”属于静态基础，“中”“后”属于每轮动态（每轮重算）
- 一条世界书如果没有内容或本轮没触发，直接跳过，不留空标题
