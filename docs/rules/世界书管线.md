# 世界书管线规则

大白话:世界书就是一堆"设定小纸条",告诉 AI 这个世界、这个人是什么样,让角色更像活人。

## 一、世界书的组成

- **书**:一本世界书,有名字、有分类、有若干**条目**。
- **条目**:标题 + 内容 + 注入位置 + 顺序 + 是否启用。
- **分类**:user 可自定义新增、改名、删除、排序。条目归入分类。

## 二、注入位置(每条条目单独选)

| 位置 | 含义 |
|---|---|
| 最高(破限) | 放在最前面的最高优先级位置 |
| 前 | 角色设定之前 |
| 中 | 聊天内容中间附近 |
| 后 | 聊天内容之后,最靠近当前这句话 |

同一位置内可手动排注入顺序(拖动排序)。

## 三、挂载规则

- **所有 AI 生成功能**都可选挂世界书:聊天、相遇、栖迟、论坛、文学城、日历日程生成、朋友圈等。
- 每个功能单独选"挂哪几本 / 哪几个分类",也可以全部不挂。
- 挂载设置存在各功能自己的设置里,但读取走统一管线。

## 四、管线流程(统一,不许各 App 另写)

1. 功能请求世界书 → 传入:功能名、角色 `charId`、挂载设置。
2. 管线取出被挂载且启用的条目。
3. 按位置分桶,桶内按顺序排。
4. 超出字数预算时:先砍"后"桶里优先级低的,"最高"桶最后才动,并记录被砍了什么。
5. 把结果交给「共用读取流程」拼进最终提示词。

## 五、必须有的操作

- 新建/编辑/删除 书、分类、条目
- 单条启用/停用(关闭方式)
- 条目复制、移动分类
- 导入/导出(跟随总备份)

## 六、反面清单

- 禁止某个 App 把世界书内容硬编码进自己的提示词。
- 禁止删分类时连带删条目而不提示;应让 user 选"条目移到未分类"或"一起删除"。
- 世界书对角色隔离:角色专属世界书只对该角色生效。
