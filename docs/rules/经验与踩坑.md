# 经验与踩坑

以后遇到反复出现的问题，把解决办法总结成简短规则补进来。

格式：一句话问题 → 一句话解决办法。

- 后台保活服务停止时，新任务刚好又开始 → 停服务用 stopSelf(最新的启动编号)，不要无条件 stopSelf()，避免把新任务的保活一起关掉
- 数据同步类前台服务系统只给约 6 小时 → 必须重写 onTimeout，到点主动停掉前台状态，否则会被系统强杀并报错
- 切后台后屏幕熄灭，长时间回复容易断网 → 回复期间持有一个带超时的局部唤醒锁，结束或超时立刻释放
- 接口地址不自动补全 → 所有格式的适配器都只对地址去掉首尾空格，原样使用，不拼接路径
- 组件里要显示用户选的图片 → 本地图片存绝对路径（以 / 开头），网络图片存 http(s) 链接，统一用 ui/image/SourceImage 显示，不要各自写加载
- 用户从相册选图后又点取消，会留下垃圾文件 → 选图先放缓存目录，点保存才用 HomeWidgetImages.commit 转正，同时清掉被替换的旧图
- 组件里的日期、星期这类会变的文字，用户可以改 → 留空表示自动跟随今天；保存时如果和自动值一样就存成空，避免第二天还停在旧日期
- 胶囊里的文字太长会压到中间的圆 → 胶囊限制最大宽度，文字走单行省略
