# 记忆系统

## 两套记忆

1. **传统总结记忆**：聊到一定量后，用「记忆总结」API 把对话总结成条目，按时间存放，可手动编辑、删除、合并
2. **纯向量记忆（重点）**：每段对话/事件生成向量，聊天时按当前话题检索最相关的几条，注入提示词

## 规则

- 每个 char 的数据完全分开：独立向量库、独立总结，互相读不到（群聊、查岗等明确互通的除外，见 App互通）
- 上下文深度由 user 自定义：最近多少条原文、取多少条向量记忆、多少条总结
- 向量记忆流程：切片 → 向量化（向量记忆 API）→ 存库 → 检索 → 可选重排（重排 API）→ 注入
- 向量只存本地数据库，分批读取，不整库载入内存
- 来源标记：每条记忆标明来自聊天、相遇、屿年、日历、情侣空间等，方便追溯和删除
- 不计入记忆的：栖迟里的「番外小剧场」；栖迟其他内容由 user 选择是否计入
- 用户可编辑、删除、关闭记忆；关闭后不再写入也不再读取
- 换向量模型时，提示重建向量，不静默丢数据
