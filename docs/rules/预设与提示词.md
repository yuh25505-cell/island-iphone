# 预设与提示词

## 结构

系统提示词拆成多个模块，用户可以：自定义排序、新增模块、开关模块、编辑、删除。

建议默认模块：最高设定 → 角色资料 → 用户资料 → 世界书（前）→ 记忆 → 世界书（中）→ 聊天记录 → 世界书（后）→ 内在驱动 → 本 App 玩法 → 回复格式。

## 共用读取流程

角色资料、用户资料、世界书、记忆，做成一套「共用读取流程」，所有 App 都走它。

每个 App 只补自己的部分：玩法、场景、任务、回复格式。

## 开发规则

1. 新 App 动手前，先写清「读什么、结束后存什么」
2. 改共用部分时，必须一起检查所有旧功能是否正常
3. 预设池共用：各 API 位置可以选用同一个预设
4. 预设可编辑、更新、删除、导入导出
5. 回复格式要求写进各 App 自己的模块，不放进共用部分
