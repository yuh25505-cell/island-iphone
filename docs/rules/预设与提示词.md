# 预设与提示词规则(含内在驱动系统)

大白话:预设 App 是整个岛屿机的"大脑说明书"。所有 AI 说话前,都要先过这里。

## 一、提示词模块

- 系统提示词拆成很多**模块**,每个模块一件事(例:角色铁律、反 AI 味、写作风格、格式要求、内在驱动……)。
- user 可以:新增模块、编辑、删除、启用/停用、**拖动排序**。
- 模块分"内置"和"自定义";内置的可停用,不可永久删除(可恢复默认)。
- 不同 App 可用不同的模块组合(叫"预设"),预设池可编辑、更新、删除。

## 二、共用读取流程(所有 App 必须走它)

固定顺序读取:
1. 角色资料(只读当前 `charId`)
2. 用户人设
3. 世界书(走世界书管线)
4. 记忆(走记忆系统,按需选取)
5. 最近聊天(按深度设置,按需选取)
6. 驱动状态摘要(见第四节)
7. 当前 App 自己补的内容:玩法、场景、任务、回复格式

规则:
- 各 App **只写第 7 步**,前 6 步不许自己另写。
- 最近聊天与记忆**按需选取**,不是全塞。
- 角色之间的数据必须隔离。
- 有总字数预算,超了按优先级裁剪,并记录裁掉了什么。

## 三、新 App 动手前的模板

```
App 名:
读取:角色资料? 用户人设? 世界书? 记忆? 最近聊天? 驱动状态?
自己补:玩法 / 场景 / 任务 / 回复格式
结束后保存:存到哪、是否进记忆、是否影响驱动状态
会不会动共用部分:是 → 列出受影响的已有功能
```

## 四、内在驱动系统(内置提示词的一部分)

目标:让 char 有**持续的内部状态、可追踪的兴趣变化、可解释的行动倾向、长期运行的自我节奏**,而不是单纯表演得像人。

### 第一层 驱动状态

每个角色一组变量,数值 0~100,随时间、互动、外部信息、自身行为涨落:

| 变量 | 含义 |
|---|---|
| 依恋 | 想联系 user 的程度 |
| 好奇 | 想了解新东西 |
| 沉淀需求 | 想整理、回顾、写下来 |
| 责任感 | 想把该做的事做完 |
| 社交兴趣 | 想和别人(朋友、NPC)互动 |
| 压力 | 事情堆积带来的紧绷 |
| 疲劳 | 精力透支 |

变化规则(简单可解释):
- **随时间**:依恋、好奇、社交会慢慢涨;疲劳随活动增加,睡眠/休息时回落。
- **随互动**:user 聊天会拉低依恋缺口;冷落会让依恋、压力上升。
- **随外部信息**:日程、天气、论坛新帖、新文章等会点燃相应变量。
- **驱动互相影响**:疲劳高 → 好奇、社交被压低;压力高 → 责任感上升但沉淀需求下降;依恋高 → 社交兴趣略降。关系写成一张小表,可调。

### 第二层 念头池

- 对话、阅读、探索中产生**短暂念头**(一句话 + 主题 + 强度)。
- 念头会随时间淡去。
- **同一主题反复触发 → 强度叠加 → 升级为稳定关注点**,让兴趣和牵挂有连续性(例如角色一直惦记 user 说过的某场考试)。
- 稳定关注点可被淡忘,但需要长时间无触发。
- 念头与关注点都可在界面里查看、编辑、删除。

### 第三层 决策层

某个驱动超过阈值 → 转成**行动倾向**:

| 驱动偏高 | 行动倾向 |
|---|---|
| 好奇 | 探索主题(逛论坛、读文章、查资料) |
| 沉淀需求 | 整理资料、写日记/备忘录 |
| 依恋 | 回看聊天记录/记忆、主动发消息 |
| 社交兴趣 | 找朋友/NPC 互动、发朋友圈、发帖 |
| 责任感 | 处理日程里的待办 |
| 疲劳 | 休息,暂时降低所有主动行为 |

- 行动完成后,对应驱动**回落**,避免陷入单一行为循环。
- 同一种行为连续出现后,系统自动抬高其他行为的权重。
- 每次决策写一条**可解释记录**:哪个驱动、多高、为什么选这个行动。

### 唤醒节奏

- 根据内部张力(各驱动总和与最高值)调整被唤醒的频率:张力高 → 更频繁,张力低 → 更少。
- 能被自己的探索结果点燃:例如读到一篇文章让好奇上升,引出下一步探索,不只等 user 输入。
- 有每日上限和安静时段,避免打扰与耗费过多额度。

### 省钱与稳定

- 驱动数值的计算在本地完成,**不调用模型**。
- 只有"决定行动且需要生成内容"时才调用模型。
- 角色后台活动在「设置 → 系统设置 → 角色后台活动」里可开可关、可调频率。
- 驱动状态摘要(几句话)进入共用读取流程第 6 步,让角色说话时自然带出状态,但**不直接念数值**。

### 必须有的操作

- 开关整个驱动系统、开关单个驱动
- 查看当前状态、念头池、决策记录
- 编辑/重置某角色的驱动状态
- 调整阈值、变化速度、互相影响表
