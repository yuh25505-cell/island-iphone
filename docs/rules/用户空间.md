# 用户空间规则

大白话:"用户空间"就是属于你的东西:你的人设、账号、你自己创建的所有内容。

## 一、用户人设

- user 可以有多个人设(名字、头像、简介、设定)。
- 每个聊天/角色可选用哪个人设。
- 人设可编辑、可删除;删除前提示哪些对话正在使用。

## 二、账号与登录(属于设置 App,仅开发者/管理员可见)

| 项目 | 规则 |
|---|---|
| 注册要素 | QQ 号(10 位数字)+ 登录密码(6 位,格式不限)+ 一次性邀请码 |
| 邀请码 | 一码一用,用过作废;管理员可生成、查看、作废 |
| 一机一码 | 一个邀请码绑定一台设备,换机需管理员处理 |
| 登录状态 | 登录后永不过期、不掉线;只有管理员注销或 user 主动退出才失效 |
| 审核 | 管理员可在岛屿机内审核注册 |
| 可见性 | 是否管理员由**服务器**判断,不是本机藏起来;普通用户界面里没有这一块 |
| 后端 | Cloudflare 免费额度(Workers + D1);基础雏形由 user 提供,后续协助完善 |

安全底线:
- 密码在服务器只存加密后的结果,永不存明文。
- 全程加密传输。
- 登录凭证存在系统密钥库里。
- 6 位密码偏弱,服务器要做尝试次数限制。

## 三、数据归属

- 所有聊天、记忆、设定都存在 user 手机里。
- 服务器只存登录相关信息,不存聊天内容。
- 清空数据、导出备份必须是 user 主动操作,清空要二次确认。
