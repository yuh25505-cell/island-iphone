# 用户空间

user 能创建的内容，每一种都必须一起做好：新建、编辑、删除；可开启的要有关闭方式。

| 内容 | 说明 |
|---|---|
| user 人设 | 可多个，可切换 |
| char | 可多个，含头像、资料、专属世界书绑定 |
| NPC | 用于朋友圈、论坛、群聊的配角 |
| 群聊 | 可拉多个 char 和 NPC |
| 私聊主题 | 私聊每个功能有类名，像 QQ 主题一样自制美化 |
| 桌面组件 | 每个组件有类名，按类名自制、导入、导出 |
| 字体 | 多个 ttf、多个 emoji 字体，两种可同时全局生效 |
| 图标、壁纸 | 自定义上传 |
| 预设、世界书 | 见对应文档 |

规则：

- 导入的主题、组件、字体要校验格式，出错时提示并不影响现有内容
- 删除前弹专属弹窗确认；正在使用的内容被删除时自动回退到默认
- 全部内容可导出导入，进入备份
- 类名一经发布不随意改名，需要改时保留旧类名兼容
