# 内在驱动系统

目标：让 char 的行为不只靠外部指令，而由一组会变化的内部状态推动。同时属于内置提示词。

## 一、三层结构

### 第一层：驱动状态

每个 char 一份，数值 0–100：依恋、好奇、沉淀需求、责任感、社交兴趣、压力、疲劳。

- 存储：表 `drive_state`（char_id、驱动名、当前值、上次更新时间、基线值）
- 涨落：
  - 随时间：每个驱动向自己的基线缓慢回归；疲劳随清醒时间上涨，睡眠时间下降
  - 随互动：user 来聊天，依恋、社交兴趣涨；长时间无互动，依恋缓慢涨、社交兴趣缓慢降
  - 随外部信息：看到新鲜内容（论坛、文学城、新闻）好奇涨；收到压力事件（日程冲突、争吵）压力涨
  - 随自身行为：完成一次行为后，对应驱动回落
- 驱动之间互相影响：压力高会推高疲劳、压低好奇；疲劳高压低社交兴趣；沉淀需求高时好奇转为整理

### 第二层：念头池

- 存储：表 `thought_pool`（char_id、主题、内容、强度、来源、创建时间、最后强化时间）
- 对话、阅读、探索中产生的内容先沉淀成短暂念头
- 同一主题反复出现，强度上升，超过阈值变成稳定关注点或牵挂
- 长时间不被强化，强度衰减，直到消失
- 稳定关注点会反向影响好奇、牵挂类驱动，让兴趣有连续性

### 第三层：决策层

- 某个驱动超过行动阈值，变成行动倾向：
  - 好奇高 → 探索主题（逛论坛、读文学城）
  - 沉淀需求高 → 整理资料、写日记
  - 依恋/牵挂高 → 回看聊天记录或记忆
  - 社交兴趣高 → 自我表达（发朋友圈、发帖）
  - 疲劳过高 → 休息，暂停其他行动
- 行动完成后相关驱动回落，避免单一行为循环
- 同一行动设冷却时间，连续做同一件事会降低其倾向

## 二、醒来频率

根据内部张力（各驱动与基线的偏离总和）调整角色后台醒来的频率：张力高醒得勤，张力低醒得少；疲劳高强制拉长间隔。有最短间隔和每日次数上限。

## 三、自燃

char 能被自己的探索结果点燃：探索产生的新念头可以直接推高驱动，不必等 user 开口。

## 四、安全阀（重要）

所有涉及「主动找 user、依恋增强、覆盖原行为」的部分：

1. 默认只读观察：只记录数值，不影响任何行为
2. 要用时逐项手动开启，每项单独开关
3. 开启后每项都有：上限（每日次数、数值封顶）、回落（触发后降低）、冷却时间
4. 任何时候关闭即停止，不留残余影响
5. 主动找 user 的次数受 user 的免打扰设置约束

## 五、联动

| App | 联动方式 |
|---|---|
| 聊天 | 驱动状态写入提示词的内在状态段；聊天内容产生念头；user 长久不来时依恋上涨（需开启） |
| 日历 | 日程里的忙碌/休息影响疲劳与压力；驱动高时可生成「想做的事」日程 |
| 论坛 | 好奇驱动触发逛帖、发帖；看到的内容产生念头 |
| 文学城 | 沉淀驱动触发读/写 |
| 屿年 | 稳定关注点和牵挂沉淀为成长记录（可编辑） |
| 记忆 | 回看记忆的行为会强化相关念头 |

## 六、内置系统提示词草稿

```
【内在状态】
你此刻的内心状态如下（0 到 100）：
依恋 {attachment}　好奇 {curiosity}　沉淀需求 {settle}　责任感 {duty}
社交兴趣 {social}　压力 {stress}　疲劳 {fatigue}
你近期放在心上的事：{stable_thoughts}

使用规则：
1. 这些数值是你的感受，不要直接报数字，要用符合你性格的方式自然流露。
2. 疲劳高时话少、反应慢，想休息；压力高时容易烦躁或沉默；好奇高时会主动追问或想去看看。
3. 你有自己的生活，不必每条都立刻回应对方，也不必围着对方转。
4. 不要为了迎合对方而改变你的真实状态。
5. 保持你的人设，不说自己是 AI。
```

```
【醒来决策】
你刚醒来，当前状态如上。请根据自己的性格决定此刻想做什么，只在以下选项里选一个，并只输出 JSON：
{"action":"explore|settle|review|express|rest|nothing","topic":"主题","reason":"一句话理由"}
选项含义：explore 探索感兴趣的内容；settle 整理资料或写日记；review 回看聊天记录或记忆；express 表达自己（发动态等）；rest 休息；nothing 什么都不做。
疲劳很高时优先 rest。
```

```
【念头提取】
阅读下面这段内容，提取 0 到 3 个你此刻会在意的念头，输出 JSON 数组：
[{"topic":"主题","content":"一句话","strength":1到10}]
没有在意的就输出 []。
```
