# 开工必读

每次开工先读这一页，再按下表去读对应文档。

## 总规则

1. 一次只做一个任务（见根目录 `开发计划.md`）
2. 不随意删除没涉及到的代码
3. 每次更新升版本号
4. 新页面/弹窗/功能都要适配日间、夜间、跟随系统，支持安卓左滑/右滑返回
5. 界面里不加小字注释和说明文字
6. 弹窗统一用专属弹窗
7. 新增可创建内容要做编辑和删除；新增可开启功能要做关闭
8. 做完用大白话告诉用户：改了什么、改了哪些文件、一共几个文件
9. 不限制上下文 token，长度由所接 API 的模型自己决定

## 文档目录

| 文件 | 管什么 | 什么时候读 |
|---|---|---|
| `docs/rules/角色与人生.md` | char 的人生、朋友、成长、不 OOC | 做任何会让 char 说话/行动的功能 |
| `docs/rules/记忆系统.md` | 总结记忆、向量记忆 | 做聊天、相遇、记忆相关 |
| `docs/rules/世界书管线.md` | 世界书注入位置、顺序、分类 | 做任何能生成内容的地方 |
| `docs/rules/预设与提示词.md` | 提示词模块、共用读取流程 | 做或改任何 App 的提示词 |
| `docs/rules/内在驱动系统.md` | 驱动状态、念头池、决策层 | 做后台活动、主动行为 |
| `docs/rules/用户空间.md` | 用户可创建的内容及规则 | 做人设、char、群聊、主题、组件、字体 |
| `docs/rules/数据存储.md` | 数据库、分页、备份 | 做任何存数据的功能 |
| `docs/rules/代码组织.md` | 文件怎么分、怎么拆 | 每次写代码前 |
| `docs/rules/界面与交互.md` | 界面通用要求 | 做任何页面/弹窗 |
| `docs/rules/App互通.md` | 16 个 App 的互通表 | 做会和别的 App 交换数据的功能 |
| `docs/rules/经验与踩坑.md` | 反复出现的问题的解决办法 | 遇到问题时、开工前扫一眼 |
| `docs/ui/` | 苹果设计规范整理（字体、颜色、动效、导航、弹窗） | 做任何界面 |

## 读文档顺序建议

- 做界面：界面与交互 → docs/ui/
- 做 AI 相关：预设与提示词 → 世界书管线 → 记忆系统 → 角色与人生
- 做存储：数据存储 → 代码组织
